The Experience Sponsorship Prospectus
The Experience

Challenge tracks & a day of intense creation.

We provide the environment, the mentorship, and the sustenance; the builders provide the ingenuity. Every project can qualify for the core Hacktoberfest challenge, and any project that also uses Gemma 4 or AWS can qualify for those too — culminating in judging and track recognition announced on stage.

Core Hacktoberfest Challenge

Best Open-Source AI Project

Build an original project where open-source or open-weight AI does real work — an agent skill, an open-weight model, or a model harness — shipped to a public GitHub repo under an open-source license.

Google Partner Challenge

Best Use of Gemma 4

Build with Gemma 4, Google's open-weight multimodal model, through the Gemini API. Understand text and images together, or move quickly from an idea to a working prototype.

AWS SBG Special

Best Use of AWS

Build or deploy your project on AWS — Lambda, S3, Bedrock, API Gateway. The strongest AWS-powered entry takes the track, on top of any Hacktoberfest challenge it also qualifies for.
