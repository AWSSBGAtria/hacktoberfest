## 🛠️ Tech Stack

- **Framework:** React 19 + Vite 6
- **Styling:** Tailwind CSS v4 with custom neon glow utilities and cyber grid
- **Icons:** Lucide React
- **Celebration Effects:** Canvas Confetti

---

## 💻 Local Development

```bash
# 1. Install dependencies
npm install

# 2. Start local dev server
npm run dev

# 3. Build for production (output to dist/)
npm run build

# 4. Preview production build
npm run preview
```

## 🌐 Deployment

The build output in `dist/` can be deployed to:
